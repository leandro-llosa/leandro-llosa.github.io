{%- comment -%} jekyll-seo-tag titles the home page " | ", because a page with no front-matter title falls through to its site_title + site_description branch. We want the bare name there, so its is switched off with title=false and built below instead. Everything else the plugin emits — og:title included — is untouched. {%- endcomment -%} {%- assign site_name = site.title | strip_html | normalize_whitespace | escape_once -%} {%- assign page_name = page.title | default: site.title | strip_html | normalize_whitespace | escape_once -%} <title>{% if page_name != site_name %}{{ page_name }} | {% endif %}{{ site_name }} {% seo title=false %} {% feed_meta %}
